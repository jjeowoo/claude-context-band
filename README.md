# context-band

Claude 데스크톱 앱(Code 탭), VS Code의 Claude Code 패널, Claude Code 터미널에서 **컨텍스트 사용량과 사용 한도를 입력창 바로 위에 항상 표시**하는 모드입니다. 데스크톱 앱에서는 [사이드바의 세션 제목 앞에 지금 하는 일](#세션-제목-표시-데스크톱-앱)도 표시합니다.

> <sub>컨텍스트 ━━─── 42% 사용 (84k / 200k) │ 세션 ━──── 5% 사용 (23분 후 재설정) │ 주간 ━━─── 22% 사용 (금요일 03:00 재설정) │ main │ bg (0)</sub>

- 데스크톱 앱과 VS Code: 끝이 둥근 막대, 터미널: 글자 막대
- 세션(5시간) 한도와 주간 한도를 한 줄에 나란히, 항목 사이는 옅은 세로 구분선으로 표시. 데스크톱 앱에서는 창이 좁아져도 줄을 바꾸지 않고, 모자란 만큼만 하나씩 숨김: 컨텍스트 토큰 수 → 주간 재설정 → '사용' 글자 → 세션 재설정 → 막대 짧게 → 막대 → 항목 이름. 가장 좁을 때도 `14% │ 6% │ 12% │ main │ bg (0)`처럼 퍼센트, 브랜치, 백그라운드 작업 수는 남음 (터미널은 다음 줄로). 구독 계정에서 앱이 받은 수치가 있을 때만 나오며, 계정 전체 수치라 마지막으로 받은 값을 다른 세션과 공유합니다. 아직 응답을 받지 않은 새 세션에도 바로 나오고, 그 사이 재설정 시각이 지난 한도는 숨깁니다. 세션 한도는 재설정까지 남은 시간(1분마다 다시 그림), 주간 한도는 재설정 요일과 시각(24시간제)을 이 PC의 시간대로 표시
- git 저장소에서 도는 세션이면 맨 오른쪽에 지금 체크아웃된 브랜치 이름을 `│ main`처럼 표시 (워크트리 세션은 브랜치 대신 `worktree`, 브랜치 없이 커밋에 있으면 커밋 앞 7자리, 24자가 넘는 이름은 잘라서 `…`로 끝냄). 브랜치를 바꾸면 Claude가 실행한 명령 직후에, 밖에서 바꿨으면 1분 안에 따라감
- 맨 끝에 이 세션에서 돌고 있는 백그라운드 작업 수를 `│ bg (2)`처럼 표시 (없으면 `bg (0)`). 에이전트는 세션 기록에서 5초마다 다시 읽어 모드를 켜기 전에 시작된 것도 셈. 백그라운드 명령과 Monitor는 시작될 때 늘고, 끝났다는 알림이 오거나 멈추면 줄어듦 (모드를 켜기 전에 시작된 것은 못 셈)
- 75% 이상 주황, 90% 이상 빨강 (한도 줄도 같음)
- 컨텍스트가 75%, 90%를 처음 넘을 때 알림 팝업 (컴팩트 후 다시 넘으면 다시 알림)
- 앱이 이미 가진 수치를 읽기만 하므로 **토큰/사용량을 추가로 쓰지 않습니다.** 알림도 대화 내용에 들어가지 않습니다.

## 세션 제목 표시 (데스크톱 앱)

사이드바의 **세션 제목 앞에 지금 하는 일을 표시**합니다. 앱의 사이드바는 작업 중이면 제목 위로 하이라이트가 지나가고 끝나면 회색 점만 남아서, 턴은 끝났지만 백그라운드에서 아직 돌고 있는 세션은 끝난 세션과 구분되지 않습니다.

| 표시 | 뜻 |
| --- | --- |
| `● 제목` | 턴이 돌고 있음 |
| `! 제목` | 질문이나 계획 승인을 기다림 |
| `◐ 제목` | 턴은 끝났지만 백그라운드 작업이나 이 세션이 띄운 세션이 아직 돎 |
| `✓ 제목` | 화면에 없는 동안 끝남. 그 세션을 열면 5초 안에 사라짐 |
| 표시 없음 | 끝났고 이미 확인함 |

- 각 세션이 앱의 이름 바꾸기 도구(`mcp__ccd_session_mgmt__set_session_title`)로 자기 제목만 바꿈. 이 도구가 권한 규칙으로 바로 허용될 때만 바꾸고, 승인 창이나 자동 모드 검사가 필요하면 아무것도 하지 않음. 그래서 `~/.claude/settings.json`에 이 규칙이 있어야 표시가 나옴:
  ```json
  "permissions": { "allow": ["mcp__ccd_session_mgmt__set_session_title"] }
  ```
- 이름 바꾸기는 대화 내용에 들어가지 않아 토큰을 쓰지 않음
- 바꿀 때마다 앱의 세션 기록에서 지금 제목을 읽어 앞 표시만 갈아 끼움. 앱이 제목을 새로 지어도 다음 상태 변화 때 다시 붙음
- 직접 지은 제목은 처음 바꿀 때 앱이 승인을 물을 수 있음. 거절하면 그 세션은 10분 동안 다시 묻지 않음
- 모드가 바꾼 제목은 앱이 더 이상 자동으로 다시 짓지 않음
- 각 세션이 5초마다 자기 상태를 `~/.claude/context-band/sessions/<세션 id>.json`에 쓰고 (바뀐 게 없으면 15초마다), 다른 세션은 이것으로 자기가 띄운 세션이 아직 일하는지 봄. 45초 넘게 안 쓰인 상태는 꺼진 세션으로 봄
- 화면에 떠 있는 세션(분할 화면이면 둘 다)은 끝나도 `✓`가 붙지 않음. 앱은 화면에 띄운 세션만 연결해 두므로, 연결이 있으면 보고 있는 것으로 봄
- 도구 권한 승인 창이 떠 있는 동안은 `●`로 보임. 앱을 작업 도중에 끄면 그 세션을 다시 열 때까지 `●`/`◐`가 남을 수 있음

## 설치 (Windows)

```
git clone https://github.com/jjeowoo/claude-context-band.git
cd claude-context-band
```

이 폴더에서 PowerShell로:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

`~/.claude/settings.json`의 `env.CLAUDE_CODE_PLUGIN_DIRS`에 이 폴더 경로를 등록합니다 (기존 설정은 `settings.json.bak`으로 백업). 앱을 껐다 켜거나 새 세션을 열면 적용됩니다.

폴더를 옮겼다면 옮긴 위치에서 `install.ps1`을 다시 실행하세요.

## 제거

```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1
```

## 다른 설치 방법: 플러그인 마켓플레이스

터미널의 Claude Code 프롬프트에서:

```
/plugin install context-band --marketplace jjeowoo/claude-context-band
```

셸에서:

```
claude plugin install context-band --marketplace jjeowoo/claude-context-band
```

데스크톱 앱에서는 프롬프트 옆 + → Plugins → Add marketplace에 `jjeowoo/claude-context-band`를 넣은 뒤 Add plugin.

이 방법을 쓸 때는 `install.ps1`로 등록한 것과 겹치지 않도록 하나만 사용하세요.

## 개발

```
claude plugin validate .
claude plugin test .
```

- `hooks/register.tsx`: 본체 (입력창 위 띠)
- `hooks/sessions.tsx`: 세션 제목 표시
- `hooks/tasks.ts`: 백그라운드 작업 수 (띠와 세션 제목 표시가 같이 씀)
- `types/index.d.ts`: 상태 타입
- `tests/band.test.tsx`, `tests/sessions.test.tsx`: 테스트
